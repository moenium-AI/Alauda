 1. ソフトの概要
----------------------------------------------------------------

Alauda は foobar2000 用の多機能 DSP コンポーネントです。
再生チェーンの中に入り、出力デバイスへ向かう音声を加工します。

自分好みの音で音楽を聴くための様々なツールを、ひとつのプラグインに
まとめてあります。それぞれを自由に組み合わせてお楽しみください。

13 のステージが決まった順序で並び、それぞれを個別に有効にできます。
リサンプラー、波形再構成、ダイナミクス復元、エンハンス、アナログ感、
サチュレーション、EQ、リバーブ、仕上げ補正、ステレオ定位、ヘッドホン、
ヘッドホン・マッチ、出力の 13 種です。

ジャンルプロファイルを選ぶと、複数のステージにまとめて設定を適用でき
ます。日本語 / 英語の表示に対応し、翻訳ファイルの追加もできます。

各ステージの詳細、全パラメーターの既定値と範囲は、オンラインマニュアルを
ご覧ください。

    https://moenium.net/alauda/manual/1.0/

 3. 動作環境
----------------------------------------------------------------

  OS        : Windows
  ホスト    : foobar2000（64bit 版のみ）
  CPU       : x86-64（Intel / AMD）
  出力       : foobar2000 が開けるオーディオデバイス

追加ソフト: 不要

32bit 版の foobar2000 には対応していません。32bit 版をお使いの場合、
DSP Manager にコンポーネントが表示されません。

処理負荷は、有効にしたステージと動作サンプルレートで決まります。
とくにリサンプラーの倍率とフィルター品質の組み合わせが最大の負荷
要因です。再生が安定しない場合は、まずこの 2 つを見直してください。

高い倍率を使う場合は、その結果のサンプルレートを受け付ける出力
デバイスが必要です。

 4. インストール方法
----------------------------------------------------------------

  1. foobar2000 を終了します。
  2. 同梱の foo_dsp_alauda.fb2k-component をダブルクリックします。
     （または foobar2000 の File > Preferences > Components を開き、
       Install... からファイルを選択します）
  3. Apply を選択します。インストールを完了するため foobar2000 が
     再起動します。

日本語表示（任意）：この配布アーカイブの `Languages\ja-JP.lng` を、
**Profiles > Open Folder** で開ける `languages` フォルダーへコピーします。
Alauda はDLLの横ではなく、foobar2000のプロファイルから翻訳ファイルを読み込みます。

インストールしただけでは再生チェーンに入りません。
続けて次の操作を行ってください。

  4. File > Preferences > Playback > DSP Manager を開きます。
  5. 「Alauda」を Active DSPs へ移動します。
  6. Configure selected で設定ウィンドウを開けます。
  7. Apply を選択します。

Active DSPs 内の順序には意味があります。Alauda より前にある DSP は
その出力を Alauda へ渡し、後ろにある DSP は Alauda の結果を処理します。

 5. 使い方
----------------------------------------------------------------

オンラインマニュアルをご覧ください。次のURLをブラウザで開きます。

    https://moenium.net/alauda/manual/1.0/

閲覧にはインターネット接続が必要です。日本語と英語を用意しています。

設定画面の Help は、現在開いているページに対応するオンライン版を
ブラウザで開きます。

はじめての場合は「クイックスタート」から読むことをおすすめします。
安全な初期状態を数分で作れる手順になっています。

インストール直後の Alauda は、意図的にほとんど何もしない状態です。
リサンプラーを含む大半のステージが無効から始まるため、導入直後に
「違いが分からない」のは正常な結果です。


----------------------------------------------------------------
 6. アンインストール方法
----------------------------------------------------------------

  1. File > Preferences > Playback > DSP Manager を開き、
     「Alauda」を Active DSPs から外します。
  2. File > Preferences > Components を開き、「Alauda DSP」を
     選択して削除します。
  3. Apply を選択し、foobar2000 を再起動します。

コンポーネントを削除すると Alauda の処理はすべて停止します。
ご自身で言語フォルダーへ置いた翻訳ファイルは、そのまま残ります。

 7. 動作に関するご注意
----------------------------------------------------------------

【音量について】

一部のステージはピークレベルや聴感上の音量を変化させます。
再生音量を下げた状態から設定を始めてください。

「出力」ページの保護機能（自動ヘッドルーム、出力保護リミッター）は
既定では無効です。ご自身で有効にしてください。

【設定の保存先】

設定は foobar2000 のプロファイル内に保存されます。コンポーネントの
パッケージには含まれないため、Alauda を更新しても設定は維持されます。

設定はページ共通のボタンでファイルへの書き出し / 読み込みができます。
大きく設定を変える前に書き出しておくと、確実に元へ戻せます。

【ヘッドホン向け機能について】

「ヘッドホン」ページのクロスフィードと仮想スピーカーは、ヘッドホン
での試聴専用です。スピーカーで使用すると、すでに音響的な回り込みが
ある信号にさらに処理をかけることになり、狭く空虚な音になります。
スピーカーで聴く際はこのページを無効にしてください。
